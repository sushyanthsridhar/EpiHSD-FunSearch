📄 LaTeX Editor — Quick Reference

Working with Claude (Cowork):
Open Cowork, describe what you want in plain English. Claude will edit your .tex file directly in your project folder. Reload this page to see the changes.

Keyboard shortcuts:
Tab → insert 2 spaces   Ctrl/⌘ S → save .tex file

Supported: $...$ inline math, $$...$$ display math, \frac, \sqrt, \sum \int \prod with limits, Greek letters, \begin{align}, \begin{theorem}, matrices, lists, sections, and more.

Auto-save: Your work is saved to localStorage every keystroke. Use Save ↓ to export as a .tex file.
