════════════════════════════════════════════════════════════════
EXECUTION ORDER
════════════════════════════════════════════════════════════════

Run the scripts in this exact order. Each one produces a CSV
that the next step or the final merger depends on.

Before running anything, install required packages once:
    pip install pandas numpy requests earthengine-api

────────────────────────────────────────────────────────────────
STEP 1  data/1_derived/build_derived.py
────────────────────────────────────────────────────────────────
What it does : Computes new features from your existing input.csv.
               No internet needed.
How to run   : python data/1_derived/build_derived.py
Time         : Under 1 minute.
Output       : data/1_derived/derived_features.csv
New features : diurnal_temp_range, consecutive_dry_weeks,
               consecutive_wet_weeks, extreme_rainfall_binary,
               cooling_degree_days, rainy_season_phase,
               school_calendar_active

────────────────────────────────────────────────────────────────
STEP 2  data/2_spatial/build_neighbor_features.py
────────────────────────────────────────────────────────────────
What it does : Computes distance-weighted neighbor incidence.
               Captures cross-province dengue spillover.
               No internet needed.
How to run   : python data/2_spatial/build_neighbor_features.py
Time         : 1 to 2 minutes.
Output       : data/2_spatial/neighbor_features.csv
New features : neighbor_incidence_lag0, neighbor_incidence_lag1,
               neighbor_incidence_lag2, n_neighbors

────────────────────────────────────────────────────────────────
STEP 3  data/3_climate_indices/fetch_enso.py
────────────────────────────────────────────────────────────────
What it does : Downloads ENSO indices from NOAA.
               Internet required. No account needed.
How to run   : python data/3_climate_indices/fetch_enso.py
Time         : Under 1 minute.
Output       : data/3_climate_indices/enso_indices.csv
New features : nino34_anom, oni_index, soi_index

────────────────────────────────────────────────────────────────
STEP 4  data/3_climate_indices/fetch_sst.py
────────────────────────────────────────────────────────────────
What it does : Downloads Caribbean SST indices from NOAA PSL.
               Internet required. No account needed.
How to run   : python data/3_climate_indices/fetch_sst.py
Time         : Under 1 minute.
Output       : data/3_climate_indices/sst_indices.csv
New features : tna_sst_anom, caribbean_sst_anom

────────────────────────────────────────────────────────────────
STEP 5  data/4_nasa_power/fetch_nasa_power.py
────────────────────────────────────────────────────────────────
What it does : Fetches solar radiation, wind speed, dew point
               from NASA POWER API for all 32 provinces.
               Internet required. No account needed.
How to run   : python data/4_nasa_power/fetch_nasa_power.py
Time         : 10 to 20 minutes. Shows progress per province.
               Safe to stop and restart. Caches each province.
Output       : data/4_nasa_power/nasa_power_features.csv
New features : solar_radiation, wind_speed, dew_point_temp

────────────────────────────────────────────────────────────────
STEP 6  data/5_remote_sensing/fetch_ndvi_lst.py   (OPTIONAL)
────────────────────────────────────────────────────────────────
What it does : Fetches NDVI and land surface temperature from
               Google Earth Engine MODIS satellite data.
Requires     : Free Google Earth Engine account.
               Run once in terminal: earthengine authenticate
How to run   : python data/5_remote_sensing/fetch_ndvi_lst.py
Time         : 30 to 60 minutes.
Output       : data/5_remote_sensing/ndvi_lst_features.csv
New features : ndvi_mean, lst_day_mean, lst_night_mean
Note         : If you skip this step, those 3 columns will be
               NaN in the final file. You can add them later.

────────────────────────────────────────────────────────────────
STEP 7  build_extended_input.py   (FINAL)
────────────────────────────────────────────────────────────────
What it does : Merges input.csv with all feature files above
               into one final extended_input.csv.
               Skips any feature file that does not exist yet.
How to run   : python build_extended_input.py
Time         : Under 1 minute.
Output       : extended_input.csv
               This is your new master dataset.
