Stage 3 — SEIR Feature Engineering (build_seir_features.py)

  • S_proxy = (population − cumulative_cases) / population
  • dI_dt = weekly Δcases (first difference)
  • Lags: cases_lag1, lag2, lag4 · temp_lag4 · rainfall_lag3
  • EIP(T) = exp(0.347·T − 9.17) — thermal forcing on β
  • Cyclical: sin(2π·week/52), cos(2π·week/52)
  • Rolling: 4-week & 8-week rolling case averages
  • Output: sindy/seir_features.csv (14,848 rows × 28 cols)

Stage 4 — Candidate Function Library

  • Polynomial terms up to degree 2 of state variables
  • Key terms: S_proxy·cases_lag1 (transmission), cases_lag1 (recovery), EIP·cases_lag1
  • Seasonal: week_sin, week_cos interactions
  • Environmental cross-terms: rainfall·EIP, humidity·cases
  • 91 candidate terms from degree-2 polynomial of 12 features

Equation Analysis
13/32 provinces EIP-driven · universal AR backbone found
✅

Stage 6 — Equation Analysis ✅

  • ✅ Universal AR backbone discovered: dI/dt ≈ −1.3·I(t−1) − 0.7·I(t−2) + 2.0·rolling_4wk — holds across all 32 provinces
  • ✅ EIP (temperature-driven transmission) survived in 13/32 provinces — all coastal/tropical; inland provinces are pure AR as expected geographically
  • ✅ S_proxy removed — biologically invalid for dengue (serotype reinfection + near-constant due to underreporting)
  • ✅ Population normalisation (incidence per 100k) made cross-province coefficients comparable and unlocked EIP signal
  • ✅ Two validation methods: M1 per-province temporal split (mean test R²=0.39, 30/32 positive), M2 all-pooled temporal (test R²=0.43)
  • ✅ Shape-weighted R² computed — provinces with sharper epidemic peaks weighted more in summary score
  • ✅ No prior SINDy paper on dengue — confirmed novel contribution

Stage 7 — LLM-FunSearch Integration

  • This stage has been elevated to a standalone project: LLM-FunSearch-SINDy (Project 3)
  • Project 2 (FunSearch-SINDy, no LLM) will first validate the evolutionary search framework using classical mutation operators
  • Project 3 will then replace the mutation step with LLM-guided proposals, using the best equations from Project 2 as seeds
  • See funsearch/roadmap.html for Project 2 progress
