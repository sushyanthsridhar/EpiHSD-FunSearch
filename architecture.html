Phase 1

SINDy

Sparse Identification of Nonlinear Dynamics. Discovers governing equations directly from weekly dengue data across 32 DR provinces.

Feature Engineering
build_seir_features.py
Constructs SEIR-relevant predictors per province in temporal order.

Susceptible proxy.
S(t) = (N − ∑τ I(τ)) / N
Target variable.
dI/dt = I[t] − I[t−1]
Thermal transmission forcing.
EIP(T) = e0.347T − 9.17  (Brady et al. 2013)
Case lags at 1, 2, 4 weeks. Rolling incidence means at 4 and 8 weeks. Temperature lag at 4 weeks. Rainfall lag at 3 weeks. Cyclical season encoding via sin and cos of week number.

Evolution Loop — per generation, per island
island.py + mutator.py + evaluator.py
1. Tournament selection of parent equation from population.
2. Structural mutation via one of 6 operators.
gradient perturb, perturb ξ, add term, remove term, swap feature, crossover
3. OLS coefficient refit.
ξ = (ΘTΘ)−1ΘT · dI/dt
4. Fitness evaluation.
F = 0.7 · R² + 0.3 · spectral score
Shape-weighted across all provinces in island.
5. Replace weakest population member if mutant improves fitness.

Phase 3

GA-FunSearch-SINDy

Genetic algorithm coordinating N parallel islands, each using simulated annealing, with LLM-guided cross-island mutation.

click for details
Data Quality Filter
run_ga_sindy.py
Drop provinces where zero rate is at least 40 percent, or total training cases are below 1,000. 11 provinces survive out of 32.

click for details
N Parallel Islands Initialised
island.py + config.py
Unlike Phase 2, islands no longer represent geographic groups. Every island trains on all 11 quality-passing provinces and independently searches the 66-term library. N is tuned via Bayesian optimisation.
↓
click for details
Epoch Loop
ga_coordinator.py
Runs MAX_EPOCHS times. Each epoch proceeds through the four stages below.
↓
click for details
Simulated Annealing — per Island
island.py
Each island runs GENERATIONS_PER_EPOCH SA steps independently.
Structural mutation → OLS refit → compute Δfitness.
Metropolis acceptance criterion.
accept if Δ > 0,   else accept with probability eΔ/T
Temperature cooling each generation.
T ← T · α  where α = SA_COOLING_RATE
↓
click for details
GA Cross-Island Selection and Crossover
ga_coordinator.py
1. Collect champion equation from each island.
2. Tournament select top K champions by fitness.
3. Crossover top 2 to produce offspring term structure.
each term included with probability 0.5
↓
click for details
LLM Structural Mutation
llm_mutator.py
Takes crossover offspring. Generates N structurally diverse variants. Algorithmic mode uses add, remove, swap, crossover operators. Claude API mode sends equation plus fitness context to Claude, which proposes one structural change. Each variant is OLS-refitted via sindy_fitter.py. Best variant selected as GA migrant.
↓
click for details
Migrant Injection into All Islands
ga_coordinator.py
GA migrant broadcast to all islands simultaneously. Replaces weakest member unconditionally. Forces cross-island gene flow every epoch regardless of fitness improvement.
↓
click for details
Final Holdout Evaluation
run_ga_sindy.py
Test years 2022 to 2023, held out throughout. Per-province R² and spectral score. Global best equation across all islands selected.
